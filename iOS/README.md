# 3-Clue X-Word: iPhone app (Phase 2)

The player app, built with Flutter. It downloads puzzles that John publishes
from the admin website (through the website's public API, `/api/v1`) and
plays them by the rules in the client specification
(`Resources/Crossword 3 Clue #3.docx`).

## Running it on this PC

Flutter is installed at `C:\src\flutter`. iPhone builds need a Mac, but the
app runs in Chrome for development:

```bash
cd iOS
flutter pub get
flutter test                                  # rules, data and screens
flutter run -d chrome --dart-define=API_BASE_URL=http://localhost:3000
```

The admin website must be running (`npm run dev` in the project root) for
puzzles to load. For a deployed website, pass its address instead:
`--dart-define=API_BASE_URL=https://your-site.vercel.app`.

Optional: `--dart-define=CONTACT_EMAIL=you@example.com` sets the address
shown under Settings → Contact us.

## How the game follows the specification

All rules live in `lib/game/game_state.dart` (pure Dart, no screens) and are
covered by `test/game_state_test.dart`.

- **Start:** the first across word (1a) is selected, its squares turn
  yellow, and its Harder clue shows.
- **Clue tabs:** Harder (yellow), Medium (pink), Easier (blue). A sun marks
  the clue being viewed. A word's squares only ever change to a "lesser"
  colour (yellow → pink → blue), so a crossing square keeps the easiest
  colour it has had. A word shows the last clue viewed whenever it's
  selected again.
- **Letters:** typed letters are red. When a word is right, its letters turn
  black and lock. A letter can also complete the crossing word. Black letters
  can't be changed or deleted; the back arrow deletes red letters backwards
  and stops at the start of the word.
- **Show Me** (grey tab, or double-tap an empty square) fills **one** letter:
  black, on white, worth 0 points.
- **Moving on:** after solving a word, the cursor moves to the next unsolved
  word: across words in number order, then down words, wrapping round. The
  grey ◀ ▶ areas show and go to the previous / next unsolved word. The ⇅ / ⇄
  button switches between the across and down word through the current
  square.
- **Tapping a square** selects the word in the current direction, or the
  other one if there's none. Tapping a black letter does nothing.
- **Scoring:** each letter scores once, when it turns black, by its square's
  colour: yellow 7, pink 5, blue 3, white (Show Me) 0.
- **Leaving** (back arrow): *I'll be back later* keeps the game; *Exit
  without saving* forgets this attempt; *Show me the completed puzzle* fills
  in the rest (0 points for those letters) and ends the game.
- **Settings:** contact email and *Restart this puzzle*.
- **Finishing:** an ad break, then the score screen with the finished grid in
  clue colours and points by colour. Progress is saved after every move.

Decisions taken (easy to change):
- **Show Me reveals one letter.** The specification describes it three ways.
- **Peeking at an easier clue lowers the colour of red (unsolved) letters
  too.** Otherwise a player could type a guess, peek, fix it, and keep the
  Harder points. Solved letters never change.
- **Players are anonymous.** Progress, scores and history stay on the phone.
- **No "players beaten" percentage yet.** The specification's table inflates
  the real figure, and there's no data on other players. The score screen
  shows the real percentage of the maximum score.

## Building for iPhone

1. On a Mac with Xcode: `flutter build ios --release
   --dart-define=API_BASE_URL=https://<site>`, then archive and upload with
   Xcode. Without a Mac, a cloud service such as Codemagic can build and
   upload from this repository.
2. You need an Apple Developer account ($99/year) to put the app on the App
   Store. The bundle identifier is `com.threecluexword.threeClueXword`
   (change it in Xcode before the first upload if you prefer another).
3. The grid uses **Arial Rounded MT Bold**, which is built into iOS, as the
   client asked.
